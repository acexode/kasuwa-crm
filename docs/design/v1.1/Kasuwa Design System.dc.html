Colour rules

  • Indigo = action & selection. Saffron = attention & highlights, never body text on white (use accent-700+).
  • Success green is for outcomes (resolved, delivered, opted-in) — not for “WhatsApp brand”.
  • Warning is orange, distinct from saffron, so “at risk” never reads as “featured”.
  • Surfaces are warm greys; pure #000 is never used.

07

Accessibility & usage notes

contrastContrast · WCAG 2.2 AA
  • Text ≥ 4.5:1, large text & UI boundaries ≥ 3:1 — input borders use neutral-500, not 300
  • Every semantic *-text token is tested on its *-soft background in both themes
  • Saffron is a fill, never text on light surfaces
touch_appTargets & focus
  • 44×44 minimum (2.5.8 asks 24; we exceed it for gloved, one-handed and cracked-screen use)
  • Focus ring: 2px gap + 2px indigo (light) / saffron (dark); never obscured by sticky headers (2.4.11)
  • Drag actions (Kanban, resize) always have a keyboard or menu alternative (2.5.7)
translateLanguage & locale
  • Set lang on names/messages (yo, ig, ha, sw, fr) so screen readers pronounce them
  • Allow +30% text expansion for French; never fixed-width buttons
  • Format numbers/currency from locale, not by string concat
  • Always show timezone next to time
signal_cellular_alt_1_barConnectivity
  • Every write is optimistic + queued; banner shows the count, never a blocking spinner
  • Low-bandwidth mode is suggested, not forced, and persists per device
  • Media shows size before download; uploads resume by chunk
Do
  • Use one primary button per view; pair destructive actions with a named confirm (“Delete 3”).
  • Put consent & DND badges next to the send/call control they affect — and disable that control.
  • Show the PCI banner for the full secure session; pause recording automatically, resume on end.
  • Use mono for phone numbers, IDs and amounts so digits align in tables.
  • Write copy in plain, warm English; short sentences; no idioms that don't translate.
Don't
  • Use telco brand colours on network chips, or WhatsApp's brand green as a UI colour.
  • Use safari, kente-as-wallpaper or map-of-Africa motifs as decoration.
  • Rely on colour alone for presence, SLA or status.
  • Truncate names — Oluwaseyifunmi and Nomvuselelo must fit; wrap to two lines instead.
  • Assume one timezone, one currency or one phone format per account.
