## What was hard

- The D-L102 rebase for a whole-graph replace: deciding the per-node merge (untouched → the
  re-read's node exactly; changed here only → mine; both → field by field, the typed value
  kept and named) so that "untouched nodes sent exactly as served" holds after any number of
  409s. Nodes are parsed into exactly the served properties so an untouched node round-trips
  byte-equal.
- The builder's not-found carries its page bundle in the RSC payload, so `admin.*` keys and
  the word "permission" in an error string made the not-found "say why" (R2). The builder now
  ships neither (its own "still connecting" line; not_permitted reworded).
- A lost completion: the retry must be the same body, revision included, so the sheet
  freezes the form and does NOT re-read after a network failure.

## Left out (by ruling or scope)

- `@p10-builder-access-404` stays a fixme (T-0079); no nav entry (R3).
- Form field bounds (maxLength, min/max, money bounds, date windows, choice option editing)
  are kept as served and set to safe defaults on a type change, not edited in the inspector.
  A new money field takes the script's existing currency, or NGN. Worth a follow-up.
- No canvas dragging (positions are layout only; new nodes go under the lowest one).
- Translation editing covers `text` only (title, hint, choice and field labels are kept as
  served and sent back whole).
