## Failures, one by one

### p18-studio.spec.ts (23 at the gate, 21 in scope after the two budget journeys)

- **17 journeys, "GET /api/v1/auth/me is not an operation the studio uses"**: spec amended (T-0130). Since T-0130
  every shell reads `/auth/me` once for the avatar. `support/custom-fields-mock.ts` now serves a contract-shaped
  `CurrentUser`, checked against `auth.openapi.yaml` when the module loads, and a query string on it is a
  violation. Every other operation stays forbidden.
- **flag-off (`/admin` bounced to sign-in)**: fixed by T-0146's admin-mock `/auth/me` answer, which came in by
  merging origin/main. No change of mine.
- **shell, "the page links nowhere"**: spec amended (T-0130). The language menu's `/translations` link moved into
  the account menu, so only two distinct links were left. The journey now opens every settings-menu group before
  it collects links, so every menu entry is checked for a 404. That check is stricter than before.
- **retire, "focus did not return to the retire control"**: bug fixed. Clicking the retire button's glyph (a
  span) also hit the row's click handler, which opened the editor behind the dialog, so focus went there. The row
  now ignores a press inside any button, link or input.
- **mobile, "scrolls sideways at 360px" (54px)**: bug fixed. The object switcher's wrapper had no `min-w-0`, so the
  segmented control pushed the page wide. It now scrolls inside its line.
- **mobile, the label not in the viewport after choosing a type**: spec amended (T-0142). On a phone the editor is
  a bottom sheet whose body scrolls. Clicking the Picklist card scrolls the body down to the card. The journey now
  scrolls the label back into view, then asserts it is in the viewport.
- **pseudo (en-XA)**: bugs fixed.
  - The Modified date is now in a `<time>`.
  - The object's api name (`contact`) is marked `data-record-text`.
  - The description tooltip (tenant text in a `title`) moved onto the aria-hidden glyph. The sr-only copy stays,
    marked as record data.
  - The currency options' names came from `Intl.DisplayNames`, which falls back to English (it did under en-XA).
    They now come from four new catalogue ids, `admin.studio.custom.currency.name.{NGN,GHS,KES,ZAR}`, in all
    eight languages. The values are CLDR's own names, taken from ICU, not invented. The symbol still comes from
    Intl. `localeReadiness` and completeness tests pass.

### p18-custom-values.spec.ts (7)

- **contact, lead, account, deal, calendar-date: "1 Mar 2027 is not the calendar date"**: spec amended (T-0143).
  T-0143 writes bare `en` as en-NG: day first, "Sep" not "Sept". `dateForms` now builds its forms from the
  browser's Intl in en-NG for bare `en`, and leaves every other language unchanged. Bug fixed alongside it: custom
  date values printed ICU's "Sept". They now go through `tidyMonth`, like every other date, with a unit test.
- **deal and edit-deal, "GET /api/v1/pipelines is not an operation the deal detail uses"**: bug fixed. The deal
  breadcrumb called `usePipelineChoices()` (listPipelines plus listMyProgrammes), which the deal contract mock
  forbids. It now names the pipeline `getPipeline` served. **This is the same change T-0147 has uncommitted in
  `deal-screen.tsx`, copied line for line so the two branches merge clean.** If T-0147 lands first, merging main
  here is a no-op for that file.
- **mobile, the slot not visible at 360**: spec amended (T-0134). At 360 the record is underline tabs with Activity
  first, and the custom values are on the Details tab. The journey clicks the Details tab (`record.section.details`
  from en.json) first.
