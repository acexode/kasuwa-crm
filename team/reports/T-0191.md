# T-0191 — Inbox realtime push

## What landed

- Outbound inbox sends append `inbox.message_persisted` (ids only) on the same
  tenant transaction as the message insert.
- The existing outbox relay publishes that type to `kasuwa.realtime.events`.
- `apps/realtime` delivers the frame only to sockets whose tenant matches and
  whose programme set was fixed at connect (including a subscribed subset).

## Outbound only

Only **OUTBOUND** sends publish today. The API send path is the only producer
of `inbox.message_persisted`. **Inbound customer messages are not covered:**
there is no inbound persist path that appends this event, so a customer reply
does not push a realtime frame. Do not treat this PR as full duplex.
