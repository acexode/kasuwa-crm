# T-0138 — P27 search and command palette to the design

Branch `agent11/T-0138-p27-search`. Screens: P27 A–A5 (top-bar dropdown), B/B1 (scope), C (results), D, D1, D2
(palette). Checked visually against `docs/design/P27/Kasuwa Search - Command.html` (D-L201: no suites run, no new
tests). Screenshots: `.artifacts/parity/app/p27-*` (1440/1024 light and dark, 360 light and dark for `/search` and
the palette) and `pair-p27-*` design/app pairs.

## What matches

- **Top-bar field (A, C).** 600px flex field, 42px, radius 10: sunken at rest with the `/` key; surface, focus edge
  and the 3px primary-soft halo when focused; clear button once typed. `/` focuses it from anywhere that is not a
  text field. On `/search` the field is the page's box (no dropdown). The dropdown's code loads on first focus.
- **Commands button.** 40px bordered, bolt, "Commands" from 1280px, Ctrl K key; opens the palette (mouse/touch).
- **Dropdown (A–A5).** 680px (600 at 1024), radius 12, shadow-3. Object chips (All + the served types that have a
  hit, no counts), Any owner / Any time menus, phone strip, grouped 52px hits with the 32px tinted tiles
  (contact primary, account info, deal success, lead accent), highlighted match (800 on accent-soft), company line,
  lead status pill, programme tag; A4 spinner line plus skeleton groups; A5 centred no-matches with Create contact /
  Create lead; footer ↑↓ Move · ↵ Open · Esc Close with "See all results →", or "Ctrl K Commands and AI" when empty.
- **Results page (C).** Back to {screen} (when known), `Results for "…"` at 26/800, Sort (Best match; Recently
  updated disabled), 260px Filters card (OBJECT boxes with icons, dimmed where no hit; OWNER/UPDATED radios), 68px
  rows with 40px tiles, type tag, status pill, company line, owner/updated columns. Content width matches C (to 1320
  at 1440). Below `md`: own field, chips instead of the filter card, rows wrap instead of truncating.
- **Palette (D, D1, D2).** T-0129 overlay behaviour via a new title-less `CommandDialog` in `@kasuwa/ui` (660px,
  96px from top ≥1280, 64px below, radius 14, full screen on phones). Bolt + 16px input + Esc key first row (no
  "Quick search" title row). SUGGESTED with 30px tiles and key chords, GO TO from the rail (live routes link, others
  disabled), typed: ACTIONS / GO TO / record groups / AI. Sunken footer with keys and the scope label. Switch
  programme step with the breadcrumb chip, initials tiles and info note.
- **Shortcuts the palette shows are real:** G then H/I/C/D/T/A/R goes to a live screen; Ctrl/Cmd+Shift+L toggles
  low-bandwidth mode (also a working palette command).
- Existing behaviour kept: planSearch/useSearch, lookups only by POST body, nothing in URLs (lookups reach the
  results page through an in-memory store, never the URL), nothing stored, latest answer wins, states kept apart.
  Test ids kept: `search-input` (palette input; `/search` phone field), `shell-search` (now the top-bar input),
  `command-palette`, `command-palette-failed`, `search-loading|empty|error|hint|invalid`, `data-hit`,
  `data-hit-type`, `data-group`, `data-see-all` (group headers), `data-search-announcement`.

## Flags added (D-L194; on in `tools/demo.mjs`, off by default)

`recent_searches` (A's empty panel), `programme_scope_search` (scope pill and menu, programme tags, Switch
programme), `ai_assistant` (Ask AI row and "? Ask AI", disabled), `search_filters` (owner/date filters and the
owner/updated columns, only "Any" choosable, dash in the columns). Read through `crmLiveNav()` like the P04 ones.
Call last contact / Create ticket / Go to wallboard reuse the rail placeholders `placeholder:calls|tickets|reports`.

## What does not match, and why

- No counts anywhere (D-P13); no "n results hidden" strip (D-L195). Added to the cut table in
  `team/reports/ui-audit/README.md`, with the other new spots below.
- Rows have no phone/city line, amount, owner or "3 days ago": the search contract serves a name, a company, a
  lead's status and a programme only. Owner/updated columns are the empty dash behind `search_filters`.
- Tickets, Conversations, KB groups/chips are not drawn (not served). Leads are (design has no lead type).
- Create contact / Create lead are disabled ("Not available yet"): the web app has no create flow yet.
- Scope menu: narrowing is not served (D-L87), so "All my programmes" is the checked choice and single programmes
  are disabled; Switch programme lists the session's programmes disabled with no "Current" pill or waiting counts.
- Facet rows and filter radios keep the components' 44px targets (design 36px).
- The top bar keeps T-0130's Lite mode switch and wordmark at 1024 (P27 omits both; P03 has them).
- Scrim uses the `bg-scrim` token (design .42 vs token .48).
- D3 (Ask AI answer) not built.
