# T-0132 — P03 Home (D-L196)

Builder: agent-11-frontend. Branch `agent11/T-0132-p03-home`. Design: `docs/design/P03/Kasuwa Home Dashboards.html`
(31 frames). Testing deferred under D-L201: no suites run, no tests written; lint and typecheck pass.

## What was built

- **Route and landing.** `/home` (`app/home/page.tsx`) behind `crm_home`; with it off `/home` is a 404.
  `landingPath()` returns `/home` wherever `crm_home` is on (D-L196 supersedes D-L172's rule; the old rule still
  applies when the flag is off). The rail and bottom-bar Home entry now links `/home`, and the wordmark goes there.
- **Header** (P03/01, /03): greeting with the first name from `getCurrentUser`, morning/afternoon/evening by the
  browser clock; day and time in the browser's zone with its name ("Tuesday 20 October · 14:47 WAT"; plain `en`
  formats day-first like en-NG, and an offset-only zone name such as "GMT+1" is replaced by the African abbreviation
  where Intl knows one). Period segmented control (Today / 7 days / 30 days / Quarter; 7d/30d/QTD on a phone).
  Currency control behind `fx_display`: ₦ NGN selected, $ USD drawn disabled (D-L69, D-L194). Customise button
  (icon only on a phone).
- **Widget grid**: 12 columns from `md`, S/M/L/XL spans, one column on a phone; each widget a card with icon,
  title, subtitle and a "…" menu (Customise Home, Remove from Home).
- **Real data** (existing BFF APIs only, nothing new on the server):
  - Today's agenda: `listCalendar` for today's window in the browser zone (tasks due today, open or done, plus
    meetings). 52px mono time column, NOW rule, muted past rows, struck-through done tasks; an open task's square
    marks it done through `updateActivity` (version + completed, nothing optimistic); a meeting's square opens
    Activities (primary for the next one).
  - Deals needing attention: `listPipelines` → `getPipeline` → `listDeals` with `owner=me` on open stages, oldest in
    stage first; rotting (danger pill "N days in Stage"), stale (warning "N days · going stale"), no next step
    (info). Amount via P06's `formatDealMoneyWhole`; link to `/deals/[id]`. Withheld fields are never shown or
    used to flag a deal.
- **Placeholder widgets** (D-L194): the design's own empty state (44px disc, title, line, CTA drawn disabled),
  never a number or a name. Flags: `ai_nba` (Next best actions, AI usage), `whatsapp_inbox`, `quota` (quota,
  forecast, leaderboard), `approvals`, `home_kpis` (pipeline by stage, tickets, queues, CSAT, programme, schedule,
  announcements, revenue, cost, profitability, SLA). Off, a widget is neither drawn nor offered.
- **Role layouts**: all five default layouts and the "Suggested for…" lists transcribed from the export. The
  session carries no role (`getCurrentUser` is identity only), so everyone starts from the sales-rep layout
  (`layoutRole()`); every other widget is reachable through Add widget.
- **Customise mode** (frames 21–23): primary banner with Reset and Done; dashed cards with earlier/later, S/M/L/XL
  and remove; HTML5 drag to reorder and a corner grip to resize (desktop); S/M/L/X keys on a focused card; dashed
  Add-widget tile; the T-0129 `Drawer` (right drawer ≥640px, bottom sheet below).
- **Layout store**: `components/home/layout-store.ts`, an async `HomeLayoutStore` interface with a localStorage
  implementation keyed by user id, Zod-parsed on load. No migration (narrowed from D-L196 by the lead).
- **Other states**: lite-mode strip (frame 24/26), new-workspace welcome (frame 28/30) when today's calendar, the
  caller's upcoming tasks and every deal in scope are empty, per-widget skeletons with a slow-connection line after
  8 s (frame 29/31).
- **Phone**: the app bar carries the logo tile, the icon-only lite switch and the avatar menu (new `brand` option on
  `CrmAppBar`, `compact` on `ShellLiteToggle`). The bottom bar on Home is Home, Inbox, Deals, Calls, More
  (Tickets instead of Deals for support/BPO) via a new `bottomObjects` prop, used only where every named entry is
  drawn in the process.
- Tokens: `LAYOUT.home*` (1368 content max, 52 time column, 170 deal-name basis, 140 add tile, 360 progress, 120 tall
  skeleton) and a `title-phone` type step (22/28/800). Eleven glyphs added to the icon subset (today,
  priority_high, target, insights, leaderboard, sentiment_satisfied, savings, check_box_outline_blank, videocam,
  map, hourglass_bottom) and the font refetched.
- 189 strings in all eight catalogues (`home.*`), validated by `pnpm i18n:validate`; plural categories per locale
  (ar six, fr three, ig/yo other only).

## Flags added

New: `crm_home`, `whatsapp_inbox`, `quota`, `approvals`, `home_kpis` — all default off, all in `tools/demo.mjs`.
Reused from main: `ai_nba` (T-0134; its description now names the Home widgets too), `fx_display` (T-0135) and
`calendar_sync` (T-0136: the empty agenda shows the design's "Connect your calendar…" with Connect calendar drawn
disabled).

## Matches the design

Header, segmented controls, customise button, card chrome, agenda rows, deal rows and pills, empty states,
customise banner and controls, add tile, drawer and sheet rows, lite strip, skeletons, welcome card, phone layout
and bottom bar, light and dark. Pairs in `.artifacts/parity/pairs/`, app shots in `.artifacts/parity/app/p03-*`
(agent user for data; `p03-home-newtenant-*` as the unassigned user).

## Does not match yet / left out

- No widget has fake content, so the populated frames for NBA, WhatsApp, quota and every manager, support, BPO and
  executive widget show their empty state instead (D-L194, by design).
- Welcome card: no "2 of 6 setup steps" count, progress bar or Continue setup button: there is no setup-steps
  source, and `/onboarding` is the admin wizard.
- Agenda: no meeting link/place/attendees, no calls, no "Join"/"Directions" (nothing on the wire); meetings use
  `groups` and open Activities. Agenda empty body reworded ("Tasks and meetings due today show here.") because
  calendar connection is not built (D-P22) — but where `calendar_sync` is on (the demo) the design's copy and a
  disabled Connect calendar are drawn.
- Deals: no account city ("Durban").
- Lite strip: "refresh every 60 s" and "Page ≈ 45 KB" dropped (neither is true today).
- Presence pill ("Available") and "· Abuja floor" not drawn (no availability or site API).
- Drawer is the T-0129 component: 400px wide (design 380), 16px title (17), header divider only on scroll; sheet
  max height 90% (78%).
- Segmented items are the component's 36px (design 38); Customise uses the 15/600 button label and 22px glyph
  (design 14/600, 20px). Phone app bar is the shell's 56px (design 60).
- Currency control hidden entirely where `fx_display` is off.
- "Recent records": the export has no such widget, so none was built.
