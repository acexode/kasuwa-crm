## What was hard

- **The not-found journey reads the inline RSC payload as page text.** `visibleText(body)`
  takes `textContent`, scripts included. Next inlines the page's message bundle into a
  `<script>`, and T-0057's create-only string "Choose the programme this account belongs to."
  matched `/belongs to/`. That check guards against the access-denied frame. The fix that is
  right anyway: the record opens the sheet to edit only, so it bundles only the edit strings
  (`ACCOUNT_EDIT_SHEET_MESSAGE_IDS`), which also saves bytes. I did not touch the spec.
  Finding for the suite writer: that regex sees every bundled string on every record page,
  so future copy containing "belongs to", "request access" and so on will trip it.
- **A flag name in a comment fails the suite.** The "no client module names a flag" check
  reads raw source, comments included. My header comment and one in the contact screen
  named `crm_accounts`. I reworded both.
- **History hygiene.** My first i18n commit picked up the two staged renames, so it did not
  build on its own. Nothing had been pushed, so I reset to the suite commit and recommitted the
  same tree as four clean commits. The tree diff against the old head (64db515) is empty.
- **The stale-complete race.** If the complete control came back before the re-read's
  version landed, a fast second click would send version 3 again. `complete()` awaits the
  re-read, and the button stays disabled until then.

  The sheet keeps T-0057's fields.

## Security review fixes (rebased onto origin/main 18a65f5)

- **Blocker, lost update after a 409** (02ae59b). The account sheet and the contact sheet now keep
  the row their form was seeded from, and the person's edits are the form's difference from that
  row. When a fresh row arrives, the form is rebased onto it. A save sends that row's version plus
  only the edited fields, with `onlyEdited` as a second guard. A field both people changed keeps
  the typed value and gets a translated note. The reviewer's two scenarios are unit-tested
  (`account-edit-rebase.test.ts`, `contact-edit-rebase.test.ts`).
- **Minors 3–6** (0e19a8e):
  - links only from uuid ids (`recordHref`, encoded);
  - the walk refuses a malformed parent id, marks the requested id as seen, and stops on a
    mismatched answer;
  - the breadcrumb draws a lock for an ancestor's withheld link and marks the limit and cycle
    endings;
  - a stale complete re-reads through the task's page.
- **Minor 8** (a60532c): the flag description and the regenerated FEATURES.md. Minor 7 was left
  as it is, as ruled.
- After the rebase, `/accounts/[id]` measured 238,706 B and `/contacts/[id]` 229,972 B.
