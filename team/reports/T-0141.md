# T-0141 — P28 Data management to the design

Builder: agent-11 (Opus 5.5). Branch `agent11/T-0141-p28-data`. Testing deferred under D-L201: no suites run
beyond the post-edit hook, the pre-commit lint and typecheck, and one look at the i18n completeness gate.

## What changed

**Data management frame** (`components/data/data-shell.tsx`). `AdminShell` with `section` ("Data management",
`database`) and no settings menu, then a 232px sub-nav (196 at 1024, a scrolling tab row on a phone), the content
column at most 1240 wide, and the sticky action bar. Routes `/admin/data/{import,duplicates,migration,exports,requests}`;
`/admin/data` opens the first live one. The admin settings menu links `d-io`, `d-dedup` and `co-dsr` into it.
Tokens added: `SHELL.dataNav` 232, `dataNavCompact` 196, `dataContent` 1240.

**Import wizard** (P28 A–A6). The T-0129 Stepper (26px circles, connectors, "Step 2 of 5 · Map fields" on a
phone). Upload: drop zone (drag-and-drop works), upload row with name, size, bar and "72% · 27.5 of 38.2 MB",
pause/resume/retry/cancel; object radio cards; programme select. Map fields: the design's table with a real
status column (matched automatically / from a previous import / chosen by you / not imported / used twice), the
summary line, the "A name" chip, and the A3 danger banner. Clean up: the two cards. Review (new, D-L128 Q6): tiles
for what is known before a run (columns, mapped, not imported, destination), the design's error table in its empty
state, and the skip-or-fix pair ("Fix the file first" turns the primary into "Choose another file"). Import: the
run card and the Recent imports table. Dark-mode inactive steps are now `surface` circles with a `border-strong`
edge, readable on the dark page.

**Duplicates** (C, C1). The sets table (Records / Why they match / Confidence / Last updated / Review), object
chips, a disabled Matching rules. The merge compare is one `<table>`: record header cards holding the main-record
radio, created date and source; a named radio group per field across the record columns; locked and withheld rows;
compliance rows with each record's value and the outcome; the success-soft Merged record column showing what
will be saved. It stacks on a phone. Behind `merge_three_way`, a disabled third slot.

**Placeholders** (D-L194): Migration (Connect step, not connected), Export centre (empty list, filters, detail
panel, New export disabled), Data requests (tiles with a dash, the table header, empty state, Log a request
disabled). No fake jobs or numbers.

**Kept**: `/contacts/import` and `/contacts/duplicates` redirect into the area when `data_management` is on; with
it off they render in the CRM shell exactly as the T-0096/T-0097 e2e contracts need: `data-shell="crm"`, the four
`data-step`s (upload, mapping, phones, run), `import-start` on the phones step, every data-testid. Checked by hand
with the flag off (steps `upload,mapping,phones,run`, one `import-start`, CRM shell).
