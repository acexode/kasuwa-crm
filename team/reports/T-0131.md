## What does not match yet

- **Copy that is data the app does not have:** "{Company} is ready", "ojafoods.kasuwa.africa", "Johannesburg region",
  "2 invites sent · 0 joined", "Go to Inbox". The app keeps its generic lines and "Go to Home" (`/admin`). The e2e
  forbids "sent" on P01/6, since nothing is sent.
- **Kept by decision (D-L195, D-P2, D-P11, T-0007b):**
  - the Workspace field on sign-in and the Password field on sign-up;
  - no carrier pill on the phone field;
  - Nigeria and Kenya tagged "Talk to sales", with the sales notes.

  These rows are added to the README's "Where an earlier cut changes the screen" table.
- **Passkey rows:** hidden. The contract's MFA method enum has no passkey, so no challenge can mark one available.
  "Sign in with a passkey" on P01/1 is unchanged and still does nothing.
- **Currency symbols:** "Ksh" and "F CFA" come from `Intl`, against the design's "KSh" and "CFA". Typing them would
  be a hard-coded symbol. US$ is fixed by formatting USD as en-NG.
- **Icons:** the design's `sync` (import in progress) and `table` (CSV tile) are not in the font subset. Adding them
  means re-fetching the font, which moves every byte budget. `refresh` and `description` stand in. Worth folding into
  the next icon batch.
- **Sizes:**
  - Continue is at least 144px wide (`min-w-36`) with 14px padding; the design has 150 and 22.
  - The skeleton widths are 8/12 and 7/12; the design has 70% and 55%.
  - Underline offset is 2px; the design has 3.
- **Not drawn:**
  - "Download our template" (P01/5.4): there is no template.
  - The invite link card's link, Copy and Share (P01/5.5): there is no link endpoint. The existing "not ready yet"
    status stays.
  - "Start" on "Make your first call": there is nowhere to go.
- **RTL:** not checked visually. Arabic is not offered by this server (awaiting review). Every new layout uses
  logical properties (`ps`/`pe`, `start`/`end`, `text-start`), and arrows and chevrons flip.
- **Low bandwidth:** not measured. Under D-L201 the byte budgets are re-pinned once, at the end. Expect P01/1 and
  P01/5.2 to move a little: the T-0128 components and the footer strings are now on these pages.

## Changes outside apps/web

- **`@kasuwa/ui` tokens:** `LAYOUT` (auth panel 520, header 64, columns 400/440/520/640, stepper 880), emitted as
  `--k-layout-*` and as spacing utilities (`w-layout-auth-panel`, `max-w-layout-column`). Regenerated.
- **`@kasuwa/ui/components`:** additive; the defaults are unchanged and the T-0128 unit-test class lists still hold.
  The 44px components could not be made 48px from the app, because a height class passed in loses to the component's
  own by CSS order.
  - `TextField`/`Select`: `size="large"` (48px, 0 14px, 16px). `TextField` also gains:
    - `invalid`: error edge, no message;
    - `trailing`: a control inside the field;
    - `labelAside`: a link beside the label, outside it.
  - `Button`: `size="large"`. A primary is 16/600.
  - `Chip`: `variant="choice"`, 40px, or 44px with `large`. Solid primary when active.
- **Feature flag `product_tour`** (D-L194): the P01/6 tour button, drawn disabled. Default off and not
  production-ready. Added to `tools/demo.mjs`.
- **i18n:** new ids in all eight catalogues, as Agent 11 candidate drafts:
  - `auth.footer.encryption`, `auth.footer.compliance` and `auth.footer.residency`. The compliance line is a
    passthrough everywhere, with its rationale.
  - `auth.locked.tellAdminSentence`.
  - `done.tour`.
  - `onboarding.skip.short`, a passthrough in pcm.

  The English `signup.signIn.prompt` now reads "Already have an account?". The other languages already say the same
  thing. `auth.locked.notYou` and `invite.emails.add` are no longer drawn but are still registered.
- **Shared lib:**
  - `lib/retry-time.ts` names zones in African English (`zoneNameLocale`), so English shows WAT/EAT/SAST.
  - `lib/money-format.ts` formats USD as en-NG.
  - `lib/mfa-fallbacks.ts` is new: the T-0126 availability rule for the passkey and backup code, kept in
    `sessionStorage` per challenge like the SMS hint.

## Behaviour changes to know about

- **Two-step Verify** is no longer disabled while the code is short. Pressing it focuses the next empty cell, so the
  button keeps the design's full colour. It is still disabled while a request runs.
- **Invites:**
  - The email box has no "Add" button. Enter, a comma, a paste or leaving the field adds the typed text.
  - The e2e selector `input[inputmode="email"]`, the chips list and the remove buttons are unchanged. The visible
    remove target is 28px; a band around it makes the target 44px.
- **"Switch to low-bandwidth mode"** now also shows the lite form while the request keeps running. Before, the
  slow-network screen stayed up.
- **Step 2's Back:**
  - goes to `/sign-up/region` when `self_serve_signup` is on;
  - is drawn disabled when it is off. That page 404s then, and a sales-provisioned tenant has no step 1 to return to.

Every `data-screen` and `data-testid` is kept.
