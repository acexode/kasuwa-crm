# T-0155 — `tools/design-intake.mjs` for bundled exports

**Task:** T-0155 · **Owner:** Cursor · **Branch:** `docs/S0-trackers`

## What changed

- **The manifest now comes from `index.txt` when there is one.** That is the file `node tools/design-parity.mjs design Pnn`
  writes (`file | size | section | label`). Intake looks in the drop first, then in `.artifacts/parity/design/<Pnn>/`. The id is
  the frame number (`P28/07`). The old " & " board form still works; `index.txt` wins when both exist.
- **A short manifest is said to be short.** A `FAILED …` line in `index.txt` prints a warning that the capture lost a frame. An
  unreadable line prints one too. No manifest at all prints the command to run. Before, a bundle gave "no index board" with
  an empty manifest and was filed anyway.
- **One folder layout: flat.** `docs/design/<Pnn>/<export file>`. Thirteen prompts already use it; only P01 has `v1.0/`. Intake no
  longer cuts a `vX.Y` folder; a re-export of the same name is printed as `replaces …`. Moving P01 was out of scope. Said in
  `docs/design/inbox/README.md` and `team/DESIGN-QUEUE.md`.
- **`--design-root=<dir>`** runs against another tree, so a fixture can be tried without touching `docs/design/`. The script runs
  `main()` only when it is the entry point, so the two extractors can be imported.
- A fixture: `tools/fixtures/design-intake/` (already an eslint-ignored path).

## Proof

`node tools/design-intake.mjs --design-root=tools/fixtures/design-intake` (a dry run; nothing moves):

```
=== P98
  manifest (board): 3 screens
    P98/1    Sign in
    P98/1a   Wrong password
    P98/2    Authenticator code
=== P99
  manifest (index.txt): 3 screens
    P99/01   Sign in · 1440 · Light
    P99/02   Wrong password · 1440 · Light
    P99/03   Account locked · 1440 · Light
  WARNING: the capture failed a frame, so the manifest is short: FAILED 04-account-slow-network: Timeout 20000ms exceeded
```

P99 is the bundle: one HTML with no " & " in its name, plus an `index.txt`. P98 is the old board form and still yields its
screens. On the real inbox (empty) intake says `Inbox is empty.`

## What was hard

I did not have a real bundled export to run, because the inbox is empty. The `index.txt` shape is read from `design-parity.mjs`'s
writer, not from a captured example. If the next bundle's capture writes a different shape, the unreadable-line warning will say so
rather than yielding an empty manifest in silence.
