# T-0160 report: realtime authentication

## What changed
- `apps/realtime` is a real gateway: `handshake.ts` (pure Upgrade decision), `scope.ts` (live scope through `withTenantTransaction`), `hub.ts` (server-side filter and subscription rule), `events.ts` (Zod schema for the Redis seam), `gateway.ts` (wiring, revalidation, liveness). The echo handler is gone.
- `docs/adr/0020-realtime-websocket-scope.md` (Proposed) records every decision. `apps/realtime/CLAUDE.md` and `.env.example` updated.
- `@kasuwa/config`: new `realtimeServeEnv()` (requires `DATABASE_URL` and `REDIS_URL`, refuses an unset `NODE_ENV`, runs the credential guard). `realtimeEnv` gains `REALTIME_ALLOWED_ORIGIN`, `REALTIME_REVALIDATE_SECONDS`, `DATABASE_POOL_MAX`, `KASUWA_SESSION_COOKIE_INSECURE`.
- Dependencies added to `apps/realtime`: `@kasuwa/db`, `@kasuwa/auth-crypto`, `pg`, `ioredis`, `zod` (all already used elsewhere in the workspace).

## What was hard / decided
- **`DATABASE_URL` and `REDIS_URL` stay optional in `realtimeEnv`.** The task file said "required". But `auth-role.acceptance` (line 1062) and `outbox.acceptance` (line 2110) call `realtimeEnv(...)` without a database, and they must pass unedited. So the requirement lives in `realtimeServeEnv`, which the process calls. The task file's line should read that way.
- Revalidation fails closed: three failed re-reads in a row close the socket. A newly granted programme is not added to a live socket; the client reconnects.
- A timer also closes the socket at `expires_at`, so expiry does not wait for a revalidation tick.

## Left out
- `connect-src` in the CSP, the web client, the ingress route (ADR lists them). Per-user connection cap and a message rate limit (frames are capped at 4 KiB). Batching revalidation by tenant.

## Verification
Unit tests for the handshake, hub, subscription rule, event parsing and config pass; lint and typecheck are clean. The acceptance suite spawns the real process against Postgres and Redis (Testcontainers), and the dialler's Docker stack is up, so it was NOT run locally. CI runs it.
