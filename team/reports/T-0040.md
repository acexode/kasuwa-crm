# T-0040 — Contact fields and accounts (Agent 3)

**State:** merged to `main` (#80), migration `0019_contact_fields_and_account.sql`.

**What changed:**
- **`account` table:**
  - programme-scoped;
  - RLS ENABLED and FORCED, one policy covering tenant and programme, with WITH CHECK = USING;
  - composite FKs, plus UNIQUE (tenant_id, programme_id, id);
  - registered in `TENANT_SCOPED_TABLES`;
  - the 0018 `updated_at` trigger is attached.
- **New `contact` columns:**
  - `owner_user_id`: composite FK to "user";
  - `status`, `source`, `preferred_channel`, `consent_state`: D-L61 CHECK value sets;
  - `tags`;
  - `preferred_language`: BCP-47 format check only;
  - `state`, `lga`, `phone_network`;
  - `dnd` and `whatsapp_opt_in`: NOT NULL, default false;
  - `account_id`: composite FK (tenant_id, programme_id, account_id) → account.
- **`version`:** an integer on both tables, kept by `app.bump_version()`. The trigger fires only when the statement left `version` unchanged (migration review M1).
- **Seed:** one account per programme.

**Evidence:**
- Lead suite: 29/29.
- schema-hygiene 8/8, rls-enforcement 11/11, features-register 11/11.
- Integration: 101/101, including the new version-trigger test.
- Tenancy review: pass. A cross-programme account link and a cross-tenant owner are both refused by the composite FKs, even for a session that can see both programmes.
- Migration review: pass with findings. M1 is fixed. B1 (full-table scans under ACCESS EXCLUSIVE, about 4.6 s at 5M rows) is accepted because no populated cell exists yet (D-L65).

**Hard parts:**
- Composite FK delete semantics. NO ACTION was chosen, because plain SET NULL would also null tenant_id and programme_id.
- `updated_at` handling while T-0011 was still unmerged.

**Open:**
- Whether an owner must belong to the contact's programme (D-L61).
- The final ON DELETE policy.
- The DND caveat: `false` means "not known", not "checked".
- The runner's non-transactional mode (D-L65).
- List indexes for "my contacts" and "contacts of account" are not built yet.
