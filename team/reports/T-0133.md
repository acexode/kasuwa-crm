## What doesn't match yet

- **Split view (frame 08) and Map (frame 12) are not built.** Split is drawn as a disabled segment on every
  list, Map only behind `map_view`. Kanban is disabled on Contacts and Accounts.
- **Accounts has no WA or Email column**: the Account contract has neither property.
- **Swipe actions are grey** (the disabled tokens) where the design shows primary / success / info: Call,
  WhatsApp and SMS are not wired (ADR-0003). Convert and Edit are live and coloured.
- **New lead / New contact are `aria-disabled`** at full fidelity (no create flow on the web yet).
- **No sticky table header or in-card scroll**: the page scrolls, so at 1440×900 the footer is below the
  fold where the design shows it pinned.
- **Header wraps the primary button to a second line when the programme pill is shown** (the design does
  the same on its BPO contacts frame).
- **Copy kept truthful where the design promises more:** search placeholders say name (and company), not
  "number, email" (R21: identifiers never go in `q`); the offline banner promises no queued edits (D-P21);
  no "Select all 64", no "Show 22 leads", no "212 contacts in this programme" (D-P13).
- **T-0129 adoption is partial:** TableBulkBar, BulkAction and Banner are used; the table itself, the menus,
  EmptyState, Skeleton and BottomSheet are still this task's markup measured to the same spec (the library
  Table has no sticky first column, and swapping the rest would have re-plumbed every test hook). One import
  each to swap later.
- **RTL not verified on screen**: the markup uses logical properties throughout, but the `ar` cookie was
  refused on this process (Arabic is not a menu locale yet), so no RTL screenshot was taken.

## Will fail at the end-of-programme gate (D-L201), by design

- `tests/e2e/p04-leads.spec.ts` and `p04-accounts.spec.ts` assert no row checkboxes (`bulk_actions` is off
  outside the demo, so these pass with flags off) and no `[data-view-option="split"]` (unbuilt segments carry
  `data-view-unavailable`, so this passes too).
- `p04-contacts.spec.ts` / `p28-import.spec.ts` expect the import link visible on the list; it is now inside
  the Import / export menu (open it first).
- `leads-model.test.ts` was updated for the new column order; other unit tests not run (D-L201). The
  post-edit hook showed two `locale.test.ts` failures mid-task that came from the incomplete French catalogue
  at the time; the i18n suite passes after the translations commit.
