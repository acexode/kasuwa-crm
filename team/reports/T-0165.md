# T-0165 — Quotes

## What changed

- Migration `0048_quotes.sql`: `quote` and `quote_line`, programme-scoped, RLS enabled and forced, D-L210-style grants. `quote_line` holds DELETE so a draft update can replace lines; `quote` does not.
- Drizzle mirror and `TENANT_SCOPED_TABLES` entries; seed one draft quote + line in PROGRAMME_A1 (kinds `1d` / `1e`).
- Domain repository: create/list/get/update/setStatus; gated transitions; version bump on draft edit; server-computed totals (line discounts then quote discount on the remainder).
- Programme action `quotes.write` (admin / tenant-admin only).
- API controllers, Zod 4 closed bodies, OpenAPI five operations, flag `crm_quotes` (already registered in the acceptance PR).
- Unit tests: totals math; service 404-before-403, `not_editable`, `invalid_transition`.

## Isolation CI fixes (Agent A1)

1. **`setQuoteStatus` HTTP status** — Nest defaults `@Post` to 201; acceptance expects 200. Added `@HttpCode(HttpStatus.OK)` on `QuotesController.setStatus`. Create remains `@HttpCode(HttpStatus.CREATED)` (201).
2. **Schema hygiene** — Dropped redundant `quote_programme_idx` on `(tenant_id, programme_id)` from `0048_quotes.sql` (and the Drizzle mirror). It is a column-prefix of unique `quote_tenant_programme_id_key` on `(tenant_id, programme_id, id)`. Migration not yet on main, so editing 0048 is OK.
