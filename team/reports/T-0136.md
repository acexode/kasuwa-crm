## What still differs, and why

- **FAB plus app-bar `add_circle`.** The design's phone frames have only the app-bar `add_circle` and no FAB. The brief
  asked for the FAB, so both are present. Please pick one; I'd drop the FAB on P07.
- **Meeting times.** These are `datetime-local` Start/End fields, not the design's Day select plus Start select. The
  pinned e2e spec fills `[data-field-input="startsAt"|"endsAt"]` datetime-locals. The duration pills set End from Start.
- **Phone dialog layout.** On a phone the shared Dialog puts the close button first (the v1.1 pattern); the P07 frame
  has it on the right.
- **Not built:** holidays, the AI brief, "N done today", "View queue", clash suggestions and "Use next free slot", and
  RSVP states. All are cut, or have no data.
- **Overdue dates** show the time too ("Mon 28 Sep 17:00"). The design drops it on some rows, but every task in the
  contract has a time.
- **Event colours.** Type colours cover only the two listed types: meeting is chart-1 and task is chart-3. The design's
  Demo, Call, Field visit and Internal types do not exist in the list contract.
- **Disabled pills.** Disabled Connect buttons and chips use the disabled tokens, so they read fainter than the export's
  live ones.
