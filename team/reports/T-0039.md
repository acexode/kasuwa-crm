# T-0039 — Records API contract, contacts first (Agent 3)

**State:** merged to `main` (#76). The contract is `docs/api/records.openapi.yaml`, and it reuses admin's `Error` schema through a relative `$ref`.

**Evidence:**
- **Lead suite:** `lead/T-0039-acceptance` passes 38/38. It was proven against 18 single-fault mutants.
- **Tenancy suites:** `api-isolation` passes 8/8 and `cursor-tampering` 5/5.
- **Redocly:** the contract is valid. The two warnings are the same two `admin.openapi.yaml` raises.

**What it pins:**
- **Paging:** keyset only, returning `{ data, nextCursor }`. There is no total, offset or page number (D-P13 is open).
- **Search and sort:** `q` accepts any format and the server normalises it to E.164. Sort keys are limited to fields field security never withholds.
- **Field security:** every read and write response carries `withheldFields`. A withheld field is omitted, never returned as null. Filtering on a withheld field returns 400 `field_withheld`.
- **Status codes:** an out-of-scope record is 404, not 403. A write the caller isn't permitted is 403 `not_permitted`. A stale update is 409 `stale_write`, and update requires `version`.
- **Read-only fields:** `dnd` and `phoneNetwork` cannot be written. If staff could clear DND by hand, the system would treat promotional traffic to that number as legal.
- **Write bodies:** they accept only E.164 phones. Update cannot change `programmeId` or `source`. Create takes a target programme, and an unreachable one returns 404.
- **Value sets:** these match D-L61.

**Drift on the live endpoints (for T-0041 to fix):**
- A bad cursor returns code `invalid_cursor`, which is not in the shared enum.
- The 404 body has no `code`.
- Responses carry no `version` and no `withheldFields`.

**Where it differs from P04:**
- Totals (D-P13).
- P04's contacts mock uses Active/Prospect/Former, and the BPO frame uses per-programme stages. The contract uses the fixed D-L61 status set.
- Score, Last activity and Company have no field yet.
- Map, kanban grouping, saved views, bulk actions, export and merge are not in the contract.

**Open:**
- The `version` column is being added in T-0040.
- Should DND ever be editable by hand?
- Should State/LGA be stored as names or as ISO 3166-2 codes?
